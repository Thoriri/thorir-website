# Website Layout Redesign Plan
## From PhD Student to Research Group Leader Presence

---

## Design Philosophy

**Current Problem**: Website presents you as "a member of a group" rather than an independent researcher/group leader.

**New Goal**: Project authority, leadership, and independence while remaining approachable to students and collaborators.

**Key Principle**: You are not just doing research - you are **leading research directions** and **building a research team**.

---

## Overall Visual Strategy

### Breaking Away from Current Design

**Current**: Generic Wowchemy Academic template, minimal theme, standard layout
- Looks like every other PhD student website
- No distinctive visual identity
- Passive, member-of-group positioning

**New**: Custom-designed, leader-focused layout
- **Bold, confident design** that stands out
- **Clear visual hierarchy** emphasizing your work
- **Active, group-leader positioning**
- **Student-facing** with clear project opportunities

### Design Elements for "Group Leader" Presence

1. **Professional Photography**
   - High-quality hero image (not just passport photo)
   - Consider: working in lab, presenting, or professional setting
   - Conveys: expertise, approachability, leadership

2. **Color Scheme**
   - Move away from basic academic blue
   - Options:
     - **Bold Academic**: Deep navy + vibrant accent (orange/teal)
     - **Modern Tech**: Dark theme with bright highlights
     - **Biomedical**: Teal/cyan + coral (reflects bio + tech)
   - Goal: Memorable and distinctive

3. **Typography**
   - Larger, bolder headings
   - Professional font pairing
   - Clear hierarchy

4. **Layout Structure**
   - Spacious, modern design
   - Clear sections with visual separation
   - Prominent CTAs (Call-to-Actions) for students

- Text: #1f2937

**Option 2: Modern Biomedical**
- Primary: #0891b2 (Cyan/Teal)

**Option 3: Tech Leader**
- Primary: #4c1d95 (Deep Purple)
- Accent: #10b981 (Emerald)
- Background: #ffffff / #f9fafb
- Text: #111827

### Typography

**Headings**:
- Font: Inter, Helvetica Neue, or Montserrat (bold, modern)
- Sizes: H1 (48px), H2 (36px), H3 (28px)

**Body**:
- Font: Inter, System UI, or Open Sans
- Size: 16-18px (larger for better readability)

**Code/Technical**:
- Font: JetBrains Mono or Fira Code

### Spacing & Layout

- **Max Content Width**: 1200px
- **Section Padding**: 80px vertical, 40px horizontal
- **Card Spacing**: 24px gap
- **Border Radius**: 8-12px for modern look
- **Shadows**: Subtle (0 4px 6px rgba(0,0,0,0.1))

## Language & Tone Adjustments

### Current vs. New Tone

**Current (Passive PhD Student)**:
- "My research interests include..."
- "I am currently a PhD student..."
- "I am working on..."

**New (Active Group Leader)**:
- "I develop..."
- "My research group investigates..."
- "I'm leading projects in..."
- "I'm looking for students to join my work on..."
- "We're exploring..."

### Key Phrases to Use

✅ **Leadership Language**:
- "I'm leading research on..."
- "My group is developing..."
- "I'm supervising X students..."
- "I'm building tools for..."
- "Our work has achieved..."

✅ **Impact Language**:
- "Enabling X through Y..."
- "Achieving 1000x efficiency..."
- "Deployed in real-world..."
- "Used by X researchers/institutions..."

✅ **Forward-Looking Language**:
- "I'm currently exploring..."
- "Next, we're investigating..."
- "I'm seeking collaborations in..."
- "Open positions available..."

❌ **Avoid**:
- "I'm interested in..." (too passive)
- "I hope to..." (uncertain)
- "Maybe..." (not confident)
- "I'm just a..." (self-deprecating)

## Technical Implementation Strategy

### Wowchemy Customization Approach

1. **Custom Homepage**
   - Create `/content/home/` widgets for each section
   - Use `widget: blank` for custom HTML
   - Order with weight parameter

2. **Custom CSS**
   - Create `/assets/scss/custom.scss`
   - Override theme variables
   - Add custom component styles

3. **Color Scheme**
   - Create `/data/themes/custom.toml`
   - Define color palette
   - Link in params.yaml

4. **New Pages**
   - Create `/content/opportunities/index.md`
   - Create `/content/research/index.md`
   - Update menu structure
